# 异世界语入门-AI汉化-CQ

《异世界语入门》（`異世界転生したけど日本語が通じなかった`）是一部日文轻小说，原作者为`Fafs F. Sashimi`。

本项目是该作品的 AI 精翻汉化版本，利用了 AiNiee & DeepSeekV4 进行主要的翻译工作，外加若干人工修正工序。主要的工作均由热心网友`苍穹(Heaveeeen)`完成。

本项目基于 Web 版进行翻译，截至目前（2026年5月）此书已经更新到了7卷半，共380小节。本项目会把这些内容全部翻译一遍。如果后续还有更新……我可能会看情况跟进。

## 项目说明

`out/`文件夹里有小说文件，你可以在这里边找到汉化版小说的电子书文件。换句话说，这里面是分发文件。（目前还没发布，因为翻译工作还没完成。）

`LICENSE.md`是关于本项目的版权说明。

`src/`文件夹是“源代码”，里面存放着中日双语的小说原文。里面带有一些特殊的标记语法。想读的话，也可以直接读这里边的东西。`src/zh_trans/`里是中文翻译，`src/jp_raw/`是日文原文，`src/bilingual_auto/`是双语对照。这些翻译文本先是均由 AiNiee & DeepSeekV4 生成，然后译者编辑了`src/zh_trans/`里的文件，以作精翻修正。

`extras/`文件夹里的东西，跟本项目没有直接关系，是一些附件，大多不是我的作品，放在这里方便取用。

`compRich.py`是一个用来编译富文本的脚本。这个脚本可以把`src/`里的那些富文本编译成纯文本或 html 以供分发。

本项目目前大致规划为如下几个大步骤：

* ai初翻：这一步在立项时就已经完成。
* 初修：基于ai初翻的文本，进行第一轮粗略的人工修正，修正明显的翻译错误、富文本格式错误、译名错误等，改掉明显不通顺的句子，把（我能发现的）ai说胡话给修掉，等等。
* 1.5修：在初修修了一半的过程中，逐渐积累经验，建立起一套更完备的翻译原则，然后根据建立好的原则，回头再去修正一遍前面的章节，使其格式、风格跟后续章节对齐。穿插在初修中间。
* 二修：等初修全部结束后，再去解决遗留下来的各种问题，尤其是一些疑难杂症，一堆标注了`FIXME`、`DOUBT`、`TODO`的地方。二修过后，基本就是成品了。

## 译者的话

本人不懂日语，但我尽力而为，我希望弄出一套……不说高质量，我希望弄出一套起码能看的翻译。我不会把 AI 拉的屎直接端出去，我了解 AI 的优缺点在哪，拒绝劣币驱逐良币。向汉化组们致以最崇高的敬意。
